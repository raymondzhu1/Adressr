# Adressr React Front End with vite.

## To Start up the project
* Make sure to cd into the directory the project lives.
* Once that's done, you can perform a npm ci as long as you have the package-lock.json.
* After that create your own .env.development file where the package.json lives. Add a variable called VITE_API_BASE_URL and then insert the URL there for the backend API.
* Then start up the project with npm run dev. Have fun!
